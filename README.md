# 🚀 Piyush Kumar Singh — Developer Portfolio

A modern, responsive personal portfolio website built with **vanilla HTML, CSS, and JavaScript** — no frameworks, no dependencies. Designed to make a strong first impression on recruiters and collaborators.

![Portfolio Preview](https://img.shields.io/badge/Status-Live-brightgreen) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌗 **Dark / Light Mode** | Theme toggle with `localStorage` persistence |
| 📱 **Fully Responsive** | Looks great on mobile (375px), tablet (768px), and desktop (1280px+) |
| 🍔 **Mobile Nav** | Animated hamburger menu with slide-in drawer |
| 🎯 **Skill Filtering** | Interactive category filter (Languages, Frontend, Backend, Tools & AI) |
| 🎬 **Scroll Animations** | Reveal-on-scroll effects using `IntersectionObserver` |
| 🧭 **Active Nav Tracking** | Navbar highlights the current section as you scroll |
| 🏗️ **Semantic HTML** | Built with `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` |
| 🎨 **Glassmorphism Header** | Frosted-glass navbar with backdrop blur |
| ✨ **Micro-animations** | Floating hero shapes, hover effects, staggered reveals |

---

## 📋 Sections

- **Hero** — Name, one-line pitch, and call-to-action buttons
- **About** — Background, education, and key highlights (CGPA, projects, certifications, SIH)
- **Skills** — 16 skill cards with interactive category filtering
- **Projects** — Featured project showcases with descriptions, tech stacks, and GitHub links
- **Contact** — Email, GitHub, LinkedIn, and phone with hover-animated cards
- **Footer** — Copyright and back-to-top button

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 (Semantic) |
| Styling | Vanilla CSS3 (Custom Properties, Grid, Flexbox, Animations) |

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Piyushsingh1212/Portfolio-1.git
   cd Portfolio-1
   ```

2. **Open in browser**
   - Simply open `index.html` in any modern browser, **or**
   - Use VS Code with the **Live Server** extension for hot-reload

3. **That's it!** No `npm install`, no build step needed.

## 📱 Responsive Breakpoints

| Device | Width | Optimizations |
|---|---|---|
| 📱 Mobile | ≤ 480px | Stacked layouts, compact cards, hamburger nav |
| 📱 Tablet | ≤ 768px | 2-column grids, slide-in nav drawer |
| 🖥️ Desktop | 1280px+ | Full grid layouts, hover effects, max-width container |

---

## 🎨 Design Highlights

- **Color Palette**: Deep navy backgrounds with vibrant purple-to-cyan accent gradients
- **Typography**: Inter (sans-serif) for body, JetBrains Mono for the logo
- **Animations**: CSS `@keyframes` for hero, JS `IntersectionObserver` for scroll reveals
- **Glassmorphism**: Frosted-glass header with `backdrop-filter: blur(20px)`
